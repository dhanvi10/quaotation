# Premium Gujarati Quotation Builder

Modern **Next.js 14** app for **સુખનાથ ઈલેક્ટ્રીકલ** — mobile-first, print-ready Gujarati quotations with English technical terms.

## Stack

- Next.js 14 + TypeScript
- Tailwind CSS + Shadcn-style UI
- TipTap (rich text clauses)
- @dnd-kit (drag & drop)
- Zustand + persist (auto-save draft)
- Framer Motion
- html2pdf.js (PDF export)
- next-themes (dark mode)

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm start
```

## Features

- Premium mobile-first UI
- Live A4 quotation preview with zoom
- Company: સુખનાથ / સિદ્ધેશ્વર / custom
- Fixed primary contact + optional secondary
- Two office addresses (editable)
- Site: શિવાય ગ્લોરી or custom
- Rich quotation points (bold, color, bullets, drag-sort)
- 5 themes + custom colors + border styles
- Logo, watermark, stamp upload
- Print, PDF download, save/load templates
- Dark mode

## Fonts

- **Baloo Bhai 2** — display headings
- **Noto Sans Gujarati** — body Gujarati
- **Poppins** — English / numbers

Legacy static version is in `/legacy`.
